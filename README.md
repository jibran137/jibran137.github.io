# Personal website

My personal site — [jibran137.github.io](https://jibran137.github.io).

Single, self-contained page: everything lives in `index.html` (inline CSS + JS, no build step, no dependencies).

## Files
- `index.html` — the whole site.
- `Jibran_Mughal_Resume.pdf` — linked from the CV button.

## Run locally
```sh
open index.html
```
Works offline; the Google Fonts `<link>` is the only thing that needs network access.

## Deploy
Hosted on GitHub Pages — pushing to `main` deploys automatically.
